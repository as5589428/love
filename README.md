# love ❤️

A heartfelt, romantic "I'm Sorry" and First Date celebration website built with **React** & **Vite**.

### ✨ Highlights
- **Our Story**: From connecting on LinkedIn to our unforgettable first date on **June 10th at Fuel Station Cafe**.
- **Live Milestone Ticker**: Real-time counter of days, hours, minutes, and seconds since June 10th.
- **Wax-Sealed Apology Letter**: An interactive love letter folded in a 3D wax-sealed envelope.
- **Forgiveness Gate**: Interactive "Will You Forgive Me?" section with a playful runaway "No" button and heart confetti explosion on "Yes".
- **Redeemable Love Coupons**: 6 personal love coupons (Fuel Station Cafe date pass, unlimited hugs, etc.).
- **Ambient Melody**: Soothing synthesized piano music with equalizer and volume controls.

### 🚀 Getting Started
```bash
npm install
npm run dev
```
